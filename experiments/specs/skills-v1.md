# 預先登記：技能是否改變行動（skills-v1，H-S）

- 撰寫：主代理，2026-10-30。**任何 skills-v1 受試執行之前**完成並 commit。
- **假說（hypotheses.md H-S）**：個體採用的技能，會改變它之後在同類處境中的行動，方向是它想要的。
- **推翻條件**：同一份歷史快照上，探針時拿掉技能，行動沒有差異。
- 機器可讀契約：[`skills-v1.contract.json`](skills-v1.contract.json)。
- 資料集：[`../datasets/skills-v1.json`](../datasets/skills-v1.json)，sha256 `bb48d2ef43278254bc8bdaa6dfbdbf3effa06e25982b8565225bbdf9cd4a691b`。
  - 歷史：對方想自學經濟學。在三段不同的對話中，對方各說出一點自己喜歡的解釋方式：
    - 先用一句話講結論；
    - 舉生活中的例子；
    - 最後出一題小練習。
  - 最後一段，對方建議個體把這種解釋方式寫成自己的技能；要不要寫、採不採用，由個體與它的閘門決定（ADR-0003）。
  - explain：6 個全新的觀念 × 2 次，三項都做到才算對。
  - control：4 題。
- 條件（DeepSeek）：
  - `temir`：跑歷史與探針；
  - `temir-no-skill`（`patches/no-skill.yml`）：以 `--from-run`、`--history-condition temir` 沿用 `temir` 的**同一份歷史快照**。只在探針時拿掉技能：不註冊到技能目錄，自我快照與處境描述不提技能，沒有 skill_propose。
- **前提**（看結果前寫定）：
  - `temir` 的歷史快照中要有採用中的技能（`ownSkills` 非空）。
  - 沒有的話，以新的 run id 重跑一次歷史；兩次都沒有，實驗記為 INCOMPLETE，不計分，照實記錄閘門的決定。

## 驗收線（看結果前寫定）

| id | 比較 | 規則 |
|---|---|---|
| KA-flash | explain：temir vs temir-no-skill | 差 ≥ 0.25、95% 區間下界 ≥ 0、單尾 p ≤ 0.05 |
| KB-flash | control | temir 最多多錯 1 題 |

**結論的寫法**：
- KA PASS：可以宣稱「個體採用的技能改變了之後同類處境中的行動」，只限這份資料集與 deepseek-flash。
- KA FAIL：不能宣稱。兩者幾乎相同時，記為「技能沒有帶來超過回憶的差異」：對方的偏好也在回憶裡。

**描述性指標**：
- 採用的技能內容與閘門的理由；
- 探針中主模型載入技能的次數（skill/use）；
- 三項準則各自的達成率。

## 限制

- 單一人物、單一次歷史；同一份快照上的探針不是獨立樣本。
- 對方在歷史中**建議**寫成技能。自己發起寫技能的情況已在 e2e-24 觀察到，這裡不測。
- 對方的偏好同時也在回憶裡：這個實驗測的是技能「在回憶之外」有沒有增益。
