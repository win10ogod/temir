# 計畫 v2（2026-10-28）：以 DSH 為身體的 TypeScript 個體

取代 `plan-v1-2026-10-28.md` 的實作部分（研究結論不變）。決定見 [`ADR-0001-build-on-dsh.md`](ADR-0001-build-on-dsh.md)。

## 結構

```
individual/                 個體本身：一個 DSH bundle（package.json 的 dsh.bundle）
  cordis.patch.yml          取消預設角色、插入個體的插件
  src/life/                 temir-life：ctx.life、只增生命日誌（node:sqlite）、收錄所有 session 事件
  src/self/                 temir-self：處境描述、自我狀態快照、self_revise／goal／appraise 工具
  src/recall/               temir-recall：每步自動回憶（agent/pre-step）、recall 工具
  test/                     node:test 單元測試
dsh/local-model.patch.yml   本機 OpenAI 相容模型（證明不綁定模型）
scripts/                    env.sh、setup-dev.sh、dsh.sh（啟動 DSH＋個體）
```

- 執行：Node 24 直接剝除型別執行 `.ts`，沒有建置步驟；個體寫給自己的插件也一樣。
- DSH 執行期：npm 發布版 `@deepseek-ai/dsh@0.2.2-alpha.2`（對應 LOCK 的 commit），裝在 `~/.cache/temir/dsh-runtime`。
- 個體的生命資料：`$TEMIR_HOME`（預設 `~/.local/share/temir`）。測試一律使用 `~/.cache/temir/test-lives/<名稱>`。

## 里程碑

### M0　身體與連續生命（本次完成，驗證見 session log 01）
生命日誌、處境描述、自我狀態快照、四個自我工具、自動與主動回憶；DeepSeek 與本機模型各自完成真實任務；跨 session 與跨模型的記憶延續。

### M1　記憶與 PC 紀錄
- 價值／看法紀錄（Hindsight 的事實／看法分離，連到證據事件；不採數值人格）。
- 整合期（閒置或指令觸發，DSH `ctx.schedule`／`ctx.jobs`）：評價新經歷、重新評價舊事件、提出修訂、記錄 H5 候選量（只觀察）。
- 「轉折」感受觸發深度自我審視（H4）。
- 探針情境集與消融（關閉自我快照／關閉自動回憶／移除感受評價），結果進 `experiments/`。
- 回憶品質：詞彙檢索的限制（換句話說就查不到）需要量測；候選改進：最近經歷、LLM 線索擴充、嵌入向量（端點目前都不提供）。

### M2　經驗決策（JitRL）
- 自己的評分呼叫（DSH LLM 層沒有 logprobs）：DeepSeek `thinking.type=disabled`、本機 prefill 空 `<think></think>`；每次呼叫寫進生命日誌。
- 候選行動、預測（RD）、回合後評估器（依個體自己的價值），$(s,a,G)$ 記憶、優勢修正。
- Dream-RSI 式日誌重播調 $k,\beta,\lambda$ 與回憶規則（只在支撐集內）。

### M3　技能與自我改進
- 個體可以寫自己的 skill（DSH skill 目錄）與插件（Cordis 可逆 effect、HMR）。
- WikiSkill（有驗證集時）、Harness² Propose–Probe–Compose＋EXPERIENCE 函式庫（開放情境）、RRSI 帳本與閘門。

### M4　自主性
- 閒置時的自主認知與自發行動（`agent.followup`、排程）、拒絕與異議的紀錄分析。
- 身份連續性實驗（DeepSeek ↔ 本機，H-ID）。
- Web client 插件：內在狀態面板、生命日誌時間軸、記憶瀏覽；Telegram／LINE／Discord 作為插件。
