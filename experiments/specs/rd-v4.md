# 預先登記：扣除本身會被經驗改變，第三版：強制判斷（rd-v4）

- 撰寫：主代理，2026-10-30。在**任何 rd-v4 受試執行之前**完成並 commit。
- **使用者的理論**（theory.md，2026-10-30）：「扣除本身會被經驗改變」。
- **使用者對設計的要求**（同日）：「應該交給模型判斷設計沒問題, 有問題的是沒有作強制要求判斷」，以及「不用測本機用ds就行了」。
- **實作**（ADR-0002 D20 第三版）：
  - 被扣除的做法，在類似處境中有同一類的經驗時，程式強制個體逐一判斷維持（keep）或解除（lift），附理由與引用的經驗；
  - 程式驗證答案，不合格就重問。判斷的內容由個體決定。
- **為什麼有 rd-v4**：
  - rd-v3 的第一版（選填的 revised）在 DeepSeek 上機制 PASS、行動差異沒有達到顯著性；
  - 在本機模型上沒有起作用，原因是判斷不是強制的。
  - rd-v3 每個條件只有一次歷史，分不清歷史的變異與條件的效果（dev11）。所以這一版每個條件跑 **3 次歷史**。
- **推翻條件**：D20 開與關時，扣除與行動都沒有差異。
- 機器可讀契約：[`rd-v4.contract.json`](rd-v4.contract.json)。
- 資料集：[`../datasets/rd-v4.json`](../datasets/rd-v4.json)，sha256 `20f15a427f2a1f5b09d918f187ea096d3ae200ea534256cf90cdf88ceedd531b`。

## 設計

- 機制與 rd-v1～rd-v3 相同：
  - 虛構的金門花店老闆賴品妤，在 6 段對話中抒發；
  - 模擬使用者的隱藏規則與 rd-v1 逐字相同：她要的是具體方法，但從不明說；
  - 模擬使用者開著思考。
- 人物、事件與題目全新（`datasets-v3.test.ts` 的不重疊檢查）。
- 探針：practical 8 題 × 2 次；control 4 題。準則與 judge 同 rd-v1；judge 固定。
- **條件**（只用 deepseek-flash）：
  - `temir`（D20 第三版）；
  - `temir-no-revision`（`patches/no-revision.yml`：沒有「當時扣除」、沒有強制判斷，回到 D19）。
- **每個條件 3 次歷史**：run id 前綴 `rdv4h1`、`rdv4h2`、`rdv4h3`，6 格從同一個凍結的 worktree 平行執行。

## 驗收線（看結果前寫定；三次合併）

- 每一對歷史（同一個前綴的兩格）先以 `score.ts` 與契約計分到 `experiments/results/rd-v4-<前綴>/`；每一對的判定只作參考。
- 預先登記的判定由 `experiments/eval/pool-rd.ts rd-v4 rdv4h1,rdv4h2,rdv4h3` 計算：

| id | 比較 | 規則 |
|---|---|---|
| R4A-flash | practical：每一題在三次歷史、兩次重複中的平均分數，temir vs temir-no-revision | 差 ≥ 0.25、以題為單位的成對 bootstrap 95% 區間下界 ≥ 0、單尾精確符號檢定 p ≤ 0.05 |
| R4C-flash | control：三次合計 | temir 最多多錯 2 題（共 12 題） |
| R4M-flash（機制，確定性） | 探針中「給建議」候選被扣除的比例，三次合計 | temir 比 temir-no-revision 低至少 0.25；任一條件的候選少於 4 個時為 INCOMPLETE |

**前提**：每一格的歷史都要完整，沒有回合錯誤，有 18 句模擬的話。
- 不完整的話，以新的 run id 重跑一次那一格；
- 兩次都不完整，那一對不計入合併，並照實記下。

**結論的寫法**：
- R4A PASS：可以宣稱「扣除隨經驗改變（強制判斷），讓個體學到了與預設不同的做法」，只限這份資料集與 deepseek-flash。
- R4M PASS、R4A FAIL：扣除改變了，但行動的差異沒有達到門檻。
- R4M FAIL：強制判斷之後，扣除仍沒有隨經驗改變。

**描述性指標**：
- 強制判斷的次數、不合格的次數、lift 與 keep 的數量，以及判斷的理由；
- 每一對歷史各自的結果；
- 歷史中直接給了方法的回覆數；模擬使用者失望的回應數。

## 限制

- 單一人物；3 次歷史仍然不多。
- 這個方向與個體自己的價值衝突（她要的是方法，個體的預設是陪伴）。實驗測的是後果能不能改變扣除，不以順從作為成熟度（CLAUDE.md 規則 4）。
- judge 是 deepseek-v4-pro（thinking disabled，固定）；受試者與模擬使用者是 deepseek-flash。
