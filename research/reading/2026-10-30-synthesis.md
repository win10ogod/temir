# 讀完之後：現有設計錯在哪裡，以及提議的方向（2026-10-30，s09；待使用者確認）

**依據**：`theory.md`（逐字）、`2026-10-30-dsh-plugins.md`、`2026-10-30-papers.md`。

**範圍**：只寫讀到的與程式中看得到的。設計方向是提議，**還沒有實作**（CLAUDE.md 規則 4）。

## 1. 理論要的

1. 「PC 影響思考、行動及經驗評價，經驗與決策又反過來改變 PC」（性質 2）。
2. 「PC 並非完全固化」（性質 1）。
3. 改變可以是非線性的（性質 4）；自我修復以穩定性與適應性為判準（性質 6）；可以形成新的穩定狀態（性質 7）。
4. 「不能擅自加入固定人格數值、任意更新公式或其他未經我確認的假設」。

照第 1 點，**思考與評價的方式本身**就屬於 PC 的作用範圍，也會被經驗改變。

### 2.2 會變的只有內容，做法從不改變

- **思考的做法**：思考（ST）、扣除（RD）、事後比對、重新評價、整合與念頭，各自的提示與輸出欄位都寫在程式裡。
  - 例如 `rd/aux.ts` 的 `deliberateSystem`、`outcomeSystem`、`REVISION_SYSTEM`，以及 `integrate/`、`thought/`。
  - 個體的自我模型只是放進這些提示的一段文字。
- **能改的與不能改的**：
  - 個體能修訂的：自我模型、敘事、目標、看法、技能、插件，以及 JitRL 的參數（重播）。
  - 不能修訂的：自己怎麼思考、怎麼評價、怎麼決定把什麼放在心上。
- **對照**：
  - Memory-Centric CL 的原文：「Feedback simply changes memory content ... while the policy itself stays fixed」，「task feedback should update not just what the agent remembers, but how it manages memory」。
  - Harness² 讓 agent 修改的正是自己的 harness：system prompt、guardrails、memory、skills、middleware。
- **結果**：本專案的「思考的 harness」不在個體可以修改的範圍內。PC 只能影響內容，影不影響做法，取決於我寫的提示。

### 2.3 判斷不是個體在自己的脈絡中做的

- **本專案**：上述判斷都由另外的輔助呼叫做。主 agent，也就是帶著全部對話脈絡、與對方說話的那一個，只收到別處產生的「準備」。
- **對照**：
  - meow-memory 從 v0.24 起規定反思與夢境「永遠在主窗口執行」；
  - dsh-memory-evolve 讓主 agent 在自己的回合內做記憶審查，由程式強制、不能略過。
- **代價**：這是否較好，本專案沒有證據；那兩個插件也沒有做對照實驗。這一點只是待檢驗的差異，不是結論。

### 2.4 個體的差異從哪裡來

- Do AI Personas Grow 的發現：只靠模型，人格的改變會收斂到平均（heterogeneity collapse）。
- 本專案的處境：類別由我固定、做法也固定，會變的只剩模型照固定框架寫出的內容。這同樣會收斂。
- 個體能夠不同，只能靠它自己的經歷，加上它自己形成的看法與做法。

## 3. 提議的方向（待使用者確認；確認之前不實作）

1. **拿掉看、歸類、評價中寫死的類別**（2.1 的表）。
   - 需要比較時，改成逐項強制模型判斷，如 D23 的「是不是同一類處境、是不是同一個做法」。
   - 個體用自己的話描述做法、輕重與掛在心上的事。
   - 撤回 D22，D22 是在強化固定的類別。
2. **把思考與評價的做法變成個體自己的、可以修訂的東西**。
   - 現在寫在程式裡的思考、扣除、比對、整合的指示，改成個體的「做法」的第一個版本，比照初始人設（規則 5）。
   - 這些做法存在生命日誌，由個體在整合時修訂。
   - 修訂走既有的閘門：Harness² 的 Propose–Probe–Compose，以改前改後的行為對照作為證據；RRSI 的帳本與雜訊下限。每次修訂都留紀錄、可以回溯。
   - 程式只保留結構性的保證：生命日誌只增不改、強制判斷的驗證（規則 2）、安全與機密。
3. **判斷放回個體自己的脈絡中**，或至少讓輔助呼叫使用個體自己的現行做法。這一點先做成可切換的條件，用實驗比較，不先下結論。
4. **固定的數字**（主動開口的節奏、沉默幾分鐘、短期記憶 7 頁……）：
   - 有論文出處的保留並標明，例如短期記憶 7 頁出自 MemoryOS。
   - 沒有出處的改成個體自己的設定，或寫成假說。
5. **每一項的效果都用真實模型的實驗檢驗**（規則 2、3）。在有數據之前，不宣稱人格因此而有所不同。
