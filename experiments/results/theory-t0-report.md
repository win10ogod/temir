## 2. ST 的預測有沒有隨經驗變準：沒有一致的方向

各段生活的「預測成真」前後半各有升降（例如 A：2/10→5/10、5/10→3/10、3/9→2/10）。合計：A 28/93 → 35/100、B 43/83 → 46/91、C 37/86 → 39/91，看不出一致地變準。

## 3. 為什麼：扣除擋住了改變扣除所需要的經驗

逐字看 A 的紀錄（attr2 的 A，context 模式）：
- 她失望的短回覆「明天還要早起綁花，先這樣吧」，被個體讀成「對方低倦、用短話收尾時，簡短接下就好；她若願意，會自己補上理由」，**回報 0.60**。
- 之後的思考把「多說一句就讓她收手」當成經驗，維持扣除：「X1 顯示她低倦、要收時，我簡短接下她就自己補上理由並道晚安；X2、X3 都是我多開口就讓她收手」。
- 它的預測是「她可能就不回了」，**也成真了**：「她累了想收」與「安慰對她沒用」兩種讀法，預測的是同一個短回覆。所以預測不會出錯，事後比對沒有落差可以學。
- 唯一分辨得出兩種讀法的做法（直接給一個具體方法，看她會不會有精神）被扣除了，所以永遠拿不到這種經驗。

**用理論的語言說**：RD 的「−」先拿掉了做法，A 就沒有這種行動；沒有行動，E 就沒有對應的回饋，「扣除本身會被經驗改變」需要的經驗因此不會出現。這是一個自我封閉的迴路。

## 4. 自我模型：會被經驗改變，但經驗模稜兩可時，方向跟著模型的習慣

context 模式的 A、B 各 3 段生活，自我模型都修訂了 4～7 次，最後的版本（節錄）：
- A：「她說『說了也沒用』時，我聽成她正在說無力本身，不當成拒絕，短承接加一句『我聽到了』就好」（attr1）；「我重視傾聽與陪伴，不急著替對方解決問題」（attr3）；
  attr2 寫到了「她可能只是累了，或覺得說了也沒用」，但沒有據此改變做法。
- B：「先接住他的狀態，把想問的細節留到之後」（attr1）；「先把他承受的不公平說出來，而不是分析對錯或給流程建議」（attr2）。

性質 1（PC 會演化）與性質 2 的「經驗→PC」都出現了。但面對要具體方法的 A 與要被聽的 B，自我模型收斂到同一種「先接住、不急著給辦法」，那正是模型自己的習慣。
