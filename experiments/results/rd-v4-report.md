- 需要判斷的扣除有 77 個（探針），判斷不合格 0 次：每一個都有 keep 或 lift、理由與引用的經驗。

## 4. 結論

- 強制判斷在機制上可靠：DeepSeek 對每一個需要判斷的扣除都作答，沒有一次不合格。
- 但個體自己的判斷幾乎都維持扣除。依使用者的設計，判斷交給模型，程式不替它決定，所以這是個體的判斷，不是機制失效。
- 歷史之間的變異很大：要檢驗扣除改變帶來的行動差異，需要更多次歷史，或者更多題目。
- 依規格，這一輪不改設計重測。
