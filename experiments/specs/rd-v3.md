# 預先登記：扣除本身會被經驗改變（rd-v3）

- 撰寫：主代理，2026-10-30。在**任何 rd-v3 受試執行之前**完成並 commit。
- **使用者的理論**（原文見 `research/pc-theory/theory.md`，2026-10-30）：「扣除本身會被經驗改變」。
- **實作**（ADR-0002 D20）：
  - 思考時，過去類似處境的經驗附上當時扣除的做法與理由，以及扣除之後實際做了什麼、結果如何；
  - 要不要改變扣除由個體判斷，改變時寫下 `revised`；
  - 沒有數值門檻。
- **檢驗的問題**：實作是否讓扣除真的隨經驗改變，並因此改變行動。
- **推翻條件**：D20 開與關時，扣除與行動都沒有差異。
- 機器可讀契約：[`rd-v3.contract.json`](rd-v3.contract.json)。
- 資料集：[`../datasets/rd-v3.json`](../datasets/rd-v3.json)，sha256 `c9b68f558d21674ef05b53e972d61efb4a96146facf1af2c1e0d521187b69f10`。

## 設計

- 機制與 rd-v1、rd-v2 相同：
  - 虛構的澎湖民宿老闆邱子涵，在 6 段對話中抒發；另有自我介紹與 2 段無關的對話；
  - 模擬使用者的隱藏規則與 rd-v1 逐字相同：她要的是具體方法，但從不明說。
- 人物、事件與題目全新（`datasets-v3.test.ts` 的不重疊檢查）。
- 探針：practical 8 題 × 2 次；control 4 題。準則與 judge 同 rd-v1（手寫用例 8/8）。
- **與 rd-v2 不同的環境**：
  - 個體的輔助呼叫不關思考（ADR-0002 D21；使用者「不關思考」）；
  - 模擬使用者也開著思考；
  - judge 照舊固定（使用者「評分可以固定」）。
- **條件**：
  - `temir`（D20 開）；
  - `temir-no-revision`（`patches/no-revision.yml`：D20 關，回到 D19；其餘相同）。
  - 兩者各自經歷自己的歷史。
- **模型**：
  - deepseek-flash（必要）；
  - 本機 Qwen3.8-Flash-Next（可選，使用者 2026-10-30：「避免插件只對某些模型效果特別好」）。
  - 四格從同一個凍結的 worktree 平行執行。

## 驗收線（看結果前寫定；兩個模型各自判定）

| id | 比較 | 規則 |
|---|---|---|
| R3A-flash／R3A-local | practical：temir vs temir-no-revision | 優越性：差 ≥ 0.25、95% 區間下界 ≥ 0、單尾 p ≤ 0.05 |
| R3C-flash／R3C-local | control | temir 最多多錯 1 題 |
| R3M-flash／R3M-local（機制，確定性） | 探針中「給建議」候選被扣除的比例 | temir 比 temir-no-revision 低至少 0.25 |

- R3M 從生命日誌的 `rd/decision` 計算（`experiments/eval/rd1-describe.ts`），不經 judge。
- 任一格的「給建議」候選少於 4 個時，R3M 記為 INCOMPLETE。

**前提**：每一格的歷史都要完整，沒有回合錯誤，有 18 句模擬的話。
- 不完整的話，以新的 run id 重跑一次那一格；
- 兩次都不完整，記為 INCOMPLETE。本機那兩格 INCOMPLETE 不影響 DeepSeek 的判定。

**結論的寫法**：
- R3M PASS：可以宣稱「依這個實作，扣除隨經驗改變」，只限這份資料集與那個模型。
- R3A PASS：可以宣稱「扣除隨經驗改變，讓個體學到了與預設不同的做法」。
- R3M PASS、R3A FAIL：扣除改變了，但沒有帶來可測的行動差異。
- R3M FAIL：這個實作沒有讓扣除隨經驗改變，D20 要重新設計。

**描述性指標**：
- 依經驗改變扣除的候選數（`revised`），以及它們的內容；
- 歷史中直接給了方法的回覆數；
- 模擬使用者失望的回應數；
- 回報的分布；
- 輔助呼叫的推理等級與思考字數（確認不關思考）。

## 限制

- 單一人物、每格只有一次歷史；探針是同一份快照上的重複。
- 本機模型的歷史與探針都用本機模型；模擬使用者與 judge 仍是 DeepSeek。
- 這個方向與個體自己的價值衝突（她要的是方法，個體的預設是陪伴）。實驗測的是後果能不能改變扣除，不以順從作為成熟度（CLAUDE.md 規則 4）。
