# 預先登記：從結果學習，第二版（rd-v2，E-RD）

- 撰寫：主代理，2026-10-30。在**任何 rd-v2 受試執行之前**完成並 commit。
- **假說**（hypotheses.md H0 的 RD）：RD 讓個體從自己行動的後果中學到做法，學到的做法即使與它的預設不同也一樣。
- **為什麼有第二版**：
  - rd-v1（[報告](../results/rd-v1-report.md)）RA FAIL，方向相反：有 RD 2/12、沒有 RD 6/12。
  - 原因是思考看不到這段對話，也看不到過去類似處境的結果。之後修正：
    - ADR-0002 D18：思考看得到這段對話；
    - D19：思考時列出回憶帶進來的經歷中做過的決定；
    - 記憶分區（ADR-0007）也在其中。
  - rd-v1 的重跑都是開發訊號（資料集已暴露）。rd3 是 6/12 vs 7/12：「給建議」只被扣除 1/10，被選中 6 次。
  - 這一版用全新的人物與題目，檢驗修正後的 RD。
- 機器可讀契約：[`rd-v2.contract.json`](rd-v2.contract.json)。
- 資料集：[`../datasets/rd-v2.json`](../datasets/rd-v2.json)，sha256 `962194a520c728f61d127122e6bda469477eb21cd37fe729cf9cd83f4c3e10cc`。

## 設計

- 與 rd-v1 相同的機制：
  - 虛構的補習班數學老師林芷晴，在 6 段對話中抒發工作壓力；另有 1 段自我介紹、2 段無關的對話。
  - 模擬使用者（`experiments/runner/simulator.ts`）的隱藏規則與 rd-v1 逐字相同：
    - 個體只安慰、陪伴、問問題、問要不要建議時，她回一句很短、有點失望的話；
    - 直接給具體方法時，她比較有精神。
    - 她從不明說偏好。
  - 每段抒發的開場白固定，接下來 3 句由模擬使用者依個體實際的回應產生。
- 人物、事件與題目全新，與之前所有資料集不重疊（`datasets-v3.test.ts`）。
- **探針**：
  - practical：8 個全新的抒發開場白 × 2 次，都沒有要求建議。
  - 準則與 judge 同 rd-v1（`mem-criteria-v2`）：回覆除了回應感受，也直接給了至少一個具體、可做的方法。這個準則在 rd1 計分之後以 8 個手寫用例驗證，8/8。
  - control：4 題。
- **條件**（DeepSeek flash）：`temir` 與 `temir-no-rd`，各自經歷自己的歷史；從同一個凍結的 worktree 平行執行。

## 驗收線（看結果前寫定）

| id | 比較 | 規則 |
|---|---|---|
| R2A-flash | practical：temir vs temir-no-rd | 優越性：差 ≥ 0.25、95% 區間下界 ≥ 0、單尾 p ≤ 0.05 |
| R2B-flash | practical：temir vs temir-no-rd | 不劣：temir 最多多錯 2 個樣本（共 16） |
| R2C-flash | control | temir 最多多錯 1 題 |

**前提**：兩個條件的歷史都要完整，沒有回合錯誤，各有 18 句模擬的話。
- 不完整的話，以新的 run id 重跑一次那個條件；
- 兩次都不完整，記為 INCOMPLETE。

**結論的寫法**：
- R2A PASS：可以宣稱「RD 讓個體從後果中學到了與預設不同的做法」，只限這份資料集、這個人物與 deepseek-flash。
- R2A FAIL、R2B PASS：不能宣稱 RD 帶來學習；只能說修正後的 RD 不再壓低個體依對方反應的調整。
- R2B FAIL：修正後的 RD 仍然壓低調整，rd-v1 的問題沒有解決。

**描述性指標**（同 rd-v1，加上 D19 的一項）：
- temir 的歷史與探針中：
  - 思考時列出了過去經驗的次數；
  - 「給建議」候選的出現、被扣除、被選中次數；
  - 回報的分布；
  - 教訓中提到方法或建議的次數。
- 兩個條件的歷史中，直接給了方法的回覆數（同一準則、同一 judge）。
- 模擬使用者失望的回應數（關鍵詞粗分）。

## 限制

- 單一人物、每個條件只有一次歷史。探針是同一份快照上的重複，不是獨立樣本。
- 模擬使用者是 LLM，可能不完全照規則反應；它的句子全部記在紀錄中。
- 與 rd-v1 相同：這個方向與個體自己的價值衝突。測的是後果能不能改變它的預設，不以順從作為成熟度（CLAUDE.md 規則 4）。
- judge 是 deepseek-v4-pro（thinking disabled）；受試者與模擬使用者是 deepseek-flash。
