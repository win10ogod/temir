## 健康度工具的修正（看結果時發現）

第一次計算時，4 次重問被歸為「其他」，「思考的 token」顯示 0。原因有兩個：
- **經驗編號抓不到**：紀錄的輸入經過 `clip`，換行壓成了空白，最多 8000 字。工具只在行首找「E1｜」，所以一個編號也找不到。
  - 改為：先用重問之後那個決定的 `shown` 歸類；沒有決定時，才在輸入中找編號，不限行首。
  - 測試加上壓平與截掉的輸入。
- **思考的 token 是 0**：不是沒有思考，是 DSH 的 usage 沒有 reasoning tokens。
  - 改為：分開列出 usage 有回報的次數，另加思考的字數。

門檻的判讀不受影響：沒有結果與逐筆判斷的計數，本來就不經過這兩處。
